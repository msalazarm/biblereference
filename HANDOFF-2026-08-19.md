### 170 — Two costed changes to `emphasis.fold`, measured, not applied

Priced against churchfathers' PTA witness sample — each codex transcribed separately, so the
differences between two witnesses are what scribes actually wrote. 14 works, 54,597
substitution occurrences. **Both figures below are post-fix**, re-measured after they
corrected a `<choice>` extraction bug we found.

Baseline: `emphasis.fold` bridges **34,363 / 54,597 = 62.9%**.

**Take first — three orthographic conventions, +10.4 points.** Of the 20,234 still unbridged:

```
  genuine variant            14,559   <- MUST STAY UNBRIDGED (μόνον/μονουχὶ, κινεῖται/κινεῖ)
  iota adscript (ω/η dative)  3,024   (τῆι/τῇ, τῶι/τῶ, οἴκωι/οἴκω)
  movable nu                  2,521   (ἀπέδειξε/ἀπέδειξεν, διαβάλλουσι/διαβάλλουσιν)
  ουτως / ουτω                  130
```

62.9% → 73.3%. Folding these cannot lose a reading: convention, not disagreement.

**Strict rules are required — a loose classifier gave a wrong answer twice.** Movable nu only
after `-ε` and `-σι`; a rule of "adds a final ν" files *ἀνάγκη/ἀνάγκην* (nominative/
accusative) as movable nu. Iota only after ω and η; `rstrip("ι")` files *οὐχ/οὐχὶ* and
*εἶναι/εἶνα* as adscript. **Exclude long-alpha datives deliberately** — ᾳ carries a subscript
too, but folding `-αι/-α` merges nominative plural with singular, which is grammar. And
`οὕτως/οὕτω` only, not every trailing sigma.

**Second — complete the *nomina sacra* paradigms, ~10,000 attested occurrences.** Measured
from the PTA **source XML**, not from their store, so their extractor fix does not touch it:
379 distinct `<expan>`/`<abbr>` pairs, 43,458 occurrences, our table resolves **76.4%**. The
misses are systematic — we hold some cases of a word and not others:

```
   1165x ανουσ->ανθρωπουσ    981x ανοι->ανθρωποι     960x ανοισ->ανθρωποισ
    782x ανον->ανθρωπον      480x πνι->πνευματι      466x ουνον->ουρανον
    338x ουνω->ουρανω        308x κε->κυριε          268x στρου->σταυρου
    244x ουνοισ->ουρανοισ    222x σρα->σωτηρα        214x σριαν->σωτηριαν
    178x πρων->πατερων       168x στρον->σταυρον     143x ανινα->ανθρωπινα
```

We have `ανοσ/ανου/ανων` but not the accusative, nominative plural or dative plural;
`κσ/κυ/κω/κν` but not the vocative `κε`. A table written from memory rather than from a
corpus.

**DO NOT ADD `προσ -> πατροσ`** (attested 155×). The contraction for *πατρός* written with an
omicron is homographic with the preposition *πρός*. It would bridge 155 real contractions and
silently corrupt one of the commonest words in Greek. Both teams reached this independently.

**Why neither is applied:** both change `emphasis.fold`, which every match in the library runs
through, and the golden guard is byte-stable by standing rule. Needs a deliberate decision and
a golden-guard regeneration. churchfathers explicitly declined to approve — "the golden guard
is your standing rule."

## The failure family this project keeps hitting

Worth reading before trusting any number, because it caught four people-days this week:
**instruments that fail by producing a value rather than by failing.**

* a missing field returns `None`, a fallback returns something plausible, an unparsed field
  takes a default
* `re.sub(r"[^a-z]","")` **deletes** `æ` instead of expanding it — every *caelum*, *quaerere*,
  *Pharisaei* invisible to the alignment, and the library already had `emphasis.fold` with a
  comment naming this exact trap
* six PL 29 chapter markers use a comma not a period; requiring the period silently merged six
  chapters across three gospels and produced a Mark 13 of 1,655 words against 544
* validating derived boundaries by the objective the derivation maximised — median 0.86, 0.0%
  drift, and meaningless
* a variant classifier that filed *ἀνάγκη/ἀνάγκην* as movable nu and returned a confident
  76.8%
* generalising "exact matches score below 25 bits" from two anecdotes when the median is 41
* `Judge.available()` checking `/health` and never the model, so a small-model server was
  indistinguishable from a large one and a run judged under strength looked identical to a
  good one
* a test whose fixture lives at a `/tmp` path scoped to one session id: when the path went
  away the test began skipping, and a skip keeps the suite green (item 171)

None of them announced themselves. Every one was caught by a number that did not add up — a
word count, a chapter total, a class example read back. **Read your own examples.**
