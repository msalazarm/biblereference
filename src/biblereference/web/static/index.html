Hover a verse and every verse beside it that carries the same text lights up. That is not a guess from verse numbers: each verse reports which verses of the pivot it covers, and two correspond when those sets meet. Hover the Douay’s Matthew 17:14 and two Greek verses light, because the one Latin verse holds both.

Covering answers with every verse needed to carry all of a verse’s text, rather than the single verse it most corresponds to. Identical for almost every verse here — where it differs is where one edition merges what another divides.

A · beside a book in the dropdown means the numbering system you have chosen does not have that book, so its shape comes from the editions that hold it.
